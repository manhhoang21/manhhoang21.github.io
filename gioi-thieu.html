Phần lớn thời gian đi làm của mình gắn với những hệ thống đã chạy nhiều năm: code legacy trên Struts, batch đêm xử lý vài trăm nghìn bản ghi mỗi lần, dữ liệu nằm rải trên Oracle, PostgreSQL, SQL Server và MySQL.

Không phải loại dự án hào nhoáng. Nhưng nó dạy mình ba thứ khó học ở chỗ khác: đọc code người khác viết, khoanh vùng ảnh hưởng trước khi sửa, và kiểm thử một luồng nghiệp vụ từ đầu đến cuối chứ không chỉ từng màn hình rời rạc.

Hiện mình đi sâu theo hướng Java / Spring Boot, xây tầng service với Spring Data JPA, hướng tới vị trí Backend Developer.

Việc mình hay làm

  • Xử lý dữ liệu khối lượng lớn qua batch và job chạy nền.
  • Đọc, bảo trì và mở rộng hệ thống legacy mà không làm vỡ thứ đang chạy.
  • Kiểm thử tích hợp toàn luồng nghiệp vụ, không dừng ở test từng màn hình.
  • Tối ưu truy vấn trên nhiều hệ quản trị cơ sở dữ liệu khác nhau.

Mình cũng dùng AI như công cụ thường trực trong ngày làm việc — tra nguyên nhân bug, soát code theo file coding rule của dự án, sinh dữ liệu test theo pattern, và tự dựng skill để tái tạo tài liệu thiết kế từ file Excel.
